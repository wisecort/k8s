# RKE2

## Versão

v1.36.4+rke2r1

## CNI

Canal.

## Control plane

- cp01: 10.255.10.130
- cp02: 10.255.10.131
- cp03: 10.255.10.132

O cp01 é o servidor inicial do cluster e mantém seu supervisor local. Os demais nós utilizam:

`https://k8s-api.k8s.internal:9345`

Não adicionar `server:` ao cp01 apenas para obter simetria.

## Kubeconfig

O kubeconfig administrativo utiliza:

`https://k8s-api.k8s.internal:6443`

Isso permite que o acesso administrativo passe pelo VIP.

## Verificação

```bash
kubectl get nodes -o wide
kubectl get pods -A
```
